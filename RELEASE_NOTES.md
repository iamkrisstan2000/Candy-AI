# Candy 1.0 — official first release

**Your offline AI chatmate for Windows 11, by KnightWin.**

Candy uses the internet **only when you explicitly run Setup Candy to download the necessary files for it to function properly—nothing else**. After setup, conversations run locally. No accounts, cloud chats, ads, telemetry or automatic update checks.

## Highlights

- GPU-first local AI with CPU fallback; verified setup downloads.
- Ten separate saved conversations, search/export/confirmed deletion and finished-only replies with safe Stop.
- Four personas and adjustable humor; custom user pictures, original Candy avatars and two seamless animated choices.
- Ten scenes, four bubble styles, coordinated Windows accents, subtle supported acrylic and compact Fluent-inspired controls.
- Original quiet sent/received sounds, playful noticeable nudge and optional installed offline Windows speech.
- Reduced motion, keyboard controls, working window captions with Settings open, local-only data and a clear destructive reset that closes without relaunching.

This finalization removes unnecessary token IPC/copies and reply polling, trims unused locale files, simplifies the README and applies **GNU GPL v3 only** to Candy's own work. App/company properties identify **KnightWin**. Third-party notices remain intact.

## Download

- **Candy-Portable-1.0.0-x64.exe** — Windows 11 Intel/AMD x64 app; no installer required.
- **Candy-source-1.0.0.zip** — matching complete Candy source, original assets, lockfile, tests, license and build/release scripts.
- **SHA256SUMS.txt** — verify downloads. The Windows workflow may also supply an optional Setup EXE.

Minimum 4 GB RAM, 8 GB+ recommended; allow several GB of free disk space and roughly 1–3 GB of initial model/runtime downloads. ARM64 is not supported. The executable is unsigned; an unknown-publisher/SmartScreen warning is possible.

**Existing users:** fully close old Candy, then open the new EXE. Experimental build data in `%APPDATA%\CandyLocal` is reused. **No reset or model reinstall is needed** for a completed compatible setup.

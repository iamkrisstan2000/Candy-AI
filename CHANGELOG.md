# Changelog

## 1.0.0 — official first release · 21 October 2026

**Candy 1.0, by KnightWin.** Earlier internal/experimental version numbers are not the official public release sequence. Existing local data remains compatible; no reset is needed.

- Local AI chatmate for Windows 11 x64; explicit setup-only downloads, pinned-file verification, GPU-first Vulkan with CPU fallback, no cloud conversation service.
- Ten saved conversations, search/export/confirmed deletion, finished-only replies, thinking animation and safe Stop.
- Four personas, adjustable humor, built-in/custom display pictures, two seamless animated Candy avatars and reduced-motion posters.
- Ten accent-coordinated scenes, Windows-inspired silk, four bubble styles, subtle supported acrylic, compact collapsible sidebar and keyboard navigation.
- Original sent/received/nudge sounds, independent mute, noticeable safe nudge motion and optional offline Windows speech.
- Working native caption controls while Settings is open; simplified Voice section; destructive whole-folder reset closes without restarting or deleting the program.
- Release cleanup: remove unused token copies/IPC and obsolete heading style; replace 40ms reply polling with one-shot final delivery scheduling; bundle only the English UI locale while preserving Unicode/ICU and installed Windows voices. No GPU-disabling production flags.
- KnightWin author/company/copyright in Windows executable metadata; matching source/build scripts; GNU GPL v3-only for Candy's own code/art/sounds with third-party notices preserved.
